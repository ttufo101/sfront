## 上传报 NETWORK_ERROR 根因与临时方案（2026-09-23 13:5x）
- 现象：管理后台走 https 后，点「上传并发布」前端报 NETWORK_ERROR，服务端 error.log 无任何 POST 记录（请求未到达 openresty/fileupload）。
- 排查确认服务端正常：① nginx `location = /api/v1/app-releases` 仅放行 POST/OPTIONS，浏览器直接 GET 该路径返回 403 是预期（用户截图即此情况，非故障）；② 本机 HTTPS OPTIONS 预检返回 204、CORS 头(Access-Control-Allow-Origin: https://106.52.77.108 等)正确；③ 本机 HTTPS POST 返回 401(token 无效被拒)，证明 fileupload 可达。
- **根因**：自签名证书。用户在地址栏点"继续访问"后主框架能打开，但 fetch/XHR（上传用此）对证书校验更严，未信任导致请求被浏览器掐掉。
- **用户选方案3（临时）**：新标签页访问 https://106.52.77.108/api/v1/app-releases（看到 403 即可，证明该 https 主机证书已信任）→ 回后台重传。Console 自测：`fetch('https://106.52.77.108/api/v1/app-releases',{method:'OPTIONS'})` 返回 204 即 OK。每次新会话/清缓存可能需重做。
- **彻底方案**：换 CA 证书（腾讯云免费证书绑域名 → DNS 解析到 106.52.77.108 → 替换 ssl/server.crt+key → reload openresty），需用户先在腾讯云申请并给域名。

## fileupload 扩展支持多平台安装包（2026-09-23 14:0x，方案 B）
- 根因：前端 ReleaseUploadPage 已支持 android/apk、ios/ipa、windows/exe、mac/dmg 四平台，但 fileupload `internal/service/file.go:validateFileType` 的 `FileKindAppRelease` 分支只认 `.apk`+ZIP 魔数；用户传 silent.exe 报 415 UNSUPPORTED_FILE_TYPE。handler 层根本没解析 platform/package_type（这两个字段被前端传但后端忽略），故后端只需"校验是合法安装包"即可。
- 改动（仅改 validateFileType 一个函数，不动调用链）：app-release 分支按扩展名+魔数放行 —— apk/ipa→ZIP 魔数；exe→PE 头 MZ(0x4d,0x5a)；dmg→仅扩展名（UDIF 魔数在文件末尾，流式读无法头部校验）。Content-Type 统一 application/octet-stream（apk 保留 vnd.android.package-archive）。
- 编译部署：/usr/local/go/bin/go build -trimpath -ldflags='-s -w' -o bin/fileupload ./cmd/server（/root/fileupload）；cp 到 /opt/fileupload/bin/fileupload 并 chown fileupload:fileupload；`systemctl restart fileupload`（systemd 服务，配置文件 /etc/systemd/system/fileupload.service，EnvironmentFile=/opt/fileupload/config/fileupload.env）。旧二进制备份 fileupload.bak.<时间戳>。
- 验证：单测（临时 _test.go 覆盖 apk/ipa/exe/dmg 通过、错误扩展名/魔数拒绝，跑完即删）PASS；端到端用自签 HS256 JWT(iss=starland,secret=starlandttfuo101,claim token_type=access 小写！注意 accessClaims.TokenType json tag 为 token_type) + 真 PE(MZ头) 文件 → POST 返回 201(file_id 生成)；对照 .txt 仍 415。修复生效。
- 备注：端到端测试在 MinIO bucket=fileupload 的 app-releases/ 下留了一个 36 字节孤立测试对象(file_id b7ee17bb-dce0-4f65-9ebe-d4d20b718371)，未走 admin 发布、不会出现在发布列表，可忽略或清理。
